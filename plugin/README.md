# hub-for-claude-code

Claude Code plugin for [Claude Hub](https://github.com/simple-YoungBadBoy/claude-hub): one skill (`/hub-for-claude-code:hub`) that installs, updates and troubleshoots the Claude Hub server and Mac app.

```
/plugin marketplace add simple-YoungBadBoy/claude-hub
/plugin install hub-for-claude-code@hub-for-claude-code
```

Then ask Claude: "install Claude Hub on this server" / "install the Claude Hub Mac app".

Community project, not affiliated with Anthropic.
