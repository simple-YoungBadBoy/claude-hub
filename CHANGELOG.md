# Changelog

## Unreleased

- 🀄 Mahjong rebuilt the way dedicated mahjong apps play it. A square table: opponents' hands face down around a felt, each player's discards in rows in front of them, a compass showing whose turn it is and how many tiles are left. Rules: exchange three (换三张, random direction), void suit, robbing a kong (抢杠胡), kong-then-discard win with the kong money handed on (杠上炮 / 呼叫转移), a passed win blocks discard wins until your next draw (过手胡), 海底, 金钩钓, 将对, 清对, 清七对, 天胡 / 地胡, refunds of kong money for players not ready (退税), and the first winner deals next. Lifting a tile shows what it leaves you waiting on and how many are left (tiles marked 听); a settlement sheet lists every player's fan and every payment. Bots now play by tiles-from-ready and useful draws, lean towards one suit or seven pairs, and only pong or kong when it helps. Cap raised to 8 fan, each round holds 1000 chips.
- Closing a session from the sidebar works in the Mac app again: tap × and then 确认关闭 (the app silently cancelled the old confirmation dialog, so nothing was closed). Closing ends the session's tmux and its Claude process, freeing the memory. ⚡ /clear also asks for a second tap.
- Faster and easier to debug when Claude is busy: a burst of hook events triggers one status poll instead of many, slow transcript reads no longer block the session list or hook handling, and the 💬 conversation view only downloads the chat again when it changed (a failed refresh keeps what is shown). API errors are now written to the server log with status and latency, without the hook noise. Image uploads time out instead of hanging, and dead terminal or event connections are cleaned up.
- New 🀄 mahjong tab: Sichuan bloody-battle rules (void suit, pong and kong, play on after a win) against three bots, with spoken calls; each round holds 500 chips from the shared stack, so you never lose more than that.
- Poker has sound effects (deal, chips, check, fold, your turn, win/lose), synthesized in the browser, with a mute button on the table.
- 💬 conversation view: tap a tool call to see the start of its result (command output, error text); calls still running are marked, so a long subagent or command no longer looks stuck.
- The usage tab shows how loaded the server is: free memory, CPU load and how much memory each session's processes take; the new-session dialog tells you the memory left and warns when it is tight. Also fixes the usage tables being squashed on the phone.
- The inspector's ± changes tab also lists the branch's recent commits, marks the ones not pushed yet (and how far behind the upstream you are), and shows each commit's message and diff.
- New session lists the folder's earlier conversations (title, last reply, when): pick one to pick it up again (`--resume`), or fork it into a new conversation to try another approach.
- Input bar completion like Claude Code's own: type `@` to pick a file or folder of the session's project (respects .gitignore), `/` to pick a command, including your own custom commands and skills. ↑↓ to choose, Tab / Enter to take it; Enter on a command runs it.
- While playing poker or on the pet / usage tab, the terminal now docks on wide screens even if you haven't opened the session yet (it picks the one that needs you most). On narrow windows and the phone a slim strip shows what each Claude session is doing; tap it to jump to the terminal.
- 📖 查看 in the terminal bar opens a read-only side panel: the conversation as chat (Markdown rendered, tool calls folded), the git changes of the session's folder with a diff per file, and a file browser that renders Markdown. ⌘-click (or tap on the phone) a file path in the terminal to open it. It only reads inside the session's working folder.
- New look options: a light "paper" theme (☀️ / 🌙 in the top bar), sessions grouped by project folder with a ＋ to start another one there, sessions needing you sorted first, and how long each has been running.
- On wide screens the active terminal stays docked on the right while you play poker or check the pet / usage (▥ to hide it).
- Input bar ⚡: one tap for /compact, /clear, /model, /effort, /context, /usage, /resume, /init.
- ⌘1–9 (or Ctrl+1–9) jumps to a session.

You get "finished / needs you / error" with the session's title — not while you're looking at an open page. Payloads are end-to-end encrypted; only browser push services are allowed.

Toggle with "⌨ 输入栏".

- Terminal upgraded to xterm.js 6.0 (fixes doubled characters with some IMEs).
